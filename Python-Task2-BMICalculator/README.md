# BMI Calculator

## Internship
Oasis Infobyte - Python Programming Internship

## Project Description
BMI Calculator is a Python-based project that calculates Body Mass Index (BMI) using the user's weight and height.

## Features
- Takes weight in kilograms.
- Takes height in meters.
- Calculates BMI using the standard formula.
- Displays BMI up to two decimal places.
- Shows BMI category.
- Handles invalid inputs.
- Validates zero and negative values.

## BMI Formula
BMI = Weight (kg) / Height (m)²

## BMI Categories
- Below 18.5: Underweight
- 18.5 - 24.9: Normal weight
- 25 - 29.9: Overweight
- 30 and above: Obese

## Technologies Used
- Python 3.11.4
- Visual Studio Code

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python bmi_calculator.py

5. Enter your weight and height when prompted.
